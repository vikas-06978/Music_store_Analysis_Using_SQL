# Music Store Analysis Using SQL
## Project Overview

This project analyzes a music store database using SQL queries. It uncovers key business insights such as identifying the top customers, bestselling artists, most popular genres by country, and sales trends. The analysis uses multiple related tables like Customers, Artists, Tracks, Albums, and Invoices to explore detailed purchase patterns.
Key Features

  - Find the senior-most employee by job title

  - Identify countries with the most invoices

  - Extract top invoice totals and best cities for sales

  - Determine the best customers who spent the most

  - Analyze rock music listeners and top rock artists

  - List tracks longer than average length

  - Calculate customer spending per artist

  - Discover the most popular genres by country

  - Find the highest spending customers per country

## Technologies Used

  - SQL for querying and analysis

  - Relational database structure

## How to Use

  - Set up the database with provided schema and data

  - Run the SQL queries as organized in question sets

  - Interpret outputs for strategic business decisions

## Future Scope

  - Expand queries for more complex user behavior insights

  - Build dashboards integrating SQL outputs for visualization
